A Solution Commerce FINAL v7

Root cause fixed:
The storefront loaded store-core.js and store-app.js as classic browser scripts. Both declared PRODUCTS in the same global lexical scope, causing the browser runtime error:
Identifier 'PRODUCTS' has already been declared

Fix:
- Isolated store-core.js inside an IIFE so its internal constants/functions do not collide with later classic scripts.
- Added a browser-style regression test that loads the exact script chain sequentially and verifies the catalog renders local products.
