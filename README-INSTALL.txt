A Solution Internal Management System — Unified Admin

Install:
1) Extract this ZIP.
2) Open your local GitHub repository folder: a/admin
3) Replace the contents of that admin folder with the files from this package's admin folder.
4) In GitHub Desktop, commit all changed/new files with: Unify A Solution internal management system
5) Push origin.
6) Wait for GitHub Pages deployment, then open /admin/

Important:
- Do not replace the public root index.html or public assets.
- This package uses the existing Supabase project and browser publishable key only.
- New editor pages included: quotation-edit.html, invoice-edit.html, activity.html.
