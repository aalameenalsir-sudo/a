# A Solution Storefront Design

## Goal
Build a production-grade bilingual English/Arabic A Solution storefront that extends the current A Solution design language into commerce.

## Core Requirements
- Preserve A Solution visual language: warm ivory, black, coral, oversized typography, architectural A, construction lines, large negative space.
- English at `/store/`, Arabic at `/ar/store/` with true RTL.
- Reciprocal canonical/hreflang links.
- Initial categories: Marketing & Advertising, Web & Digital Products, Technology, Brand & Design, Events & Experiences, Consulting, Media & Content.
- Initial featured offers: Website Development, eCommerce Store, CRM System, Brand Identity, Digital Marketing Package.
- Shared cart state across locales.
- SAR locale-aware price formatting.
- Secrets never in browser code.
- Current main site remains visually intact.

## Acceptance
Desktop/mobile responsive, bilingual, A Solution-native visual system, working catalog rendering, cart add/remove/total, and clear path to Supabase checkout/orders.
