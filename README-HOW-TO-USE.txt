A SOLUTION — WEBSITE FILES
==========================

WHAT'S INSIDE
  index.html    the full landing page (static, ready to open in a browser)
  styles.css    all styles for the page
  images/       logo, favicon and all mockup images
  robots.txt    basic search-engine file

HOW TO USE

1) Any hosting / cPanel / Netlify / Vercel:
   upload the whole folder contents to the public root (public_html / htdocs).
   The page is index.html — no build step, no server needed.

2) WordPress:
   Option A (recommended): install a plugin that allows custom HTML pages
   (e.g. "Insert HTML Snippet" or a page builder's "Custom HTML" block),
   create a new page, paste the contents of index.html <body>, and add
   styles.css through Appearance > Customize > Additional CSS.
   Upload the images from images/ via Media Library and update the
   image src paths to the new Media URLs.

   Option B: upload the folder via FTP to /wp-content/asolution-site/
   and link to /wp-content/asolution-site/index.html as a standalone page.

3) Editing text:
   open index.html in any editor and change the wording directly.
   Brand colors are defined at the top of styles.css.
